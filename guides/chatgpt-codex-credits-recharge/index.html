Codex Credits多少钱？10美元、20美元能买多少？

Codex额外Credits并不是按照固定聊天次数出售。

用户购买的是可以用于适用功能的额外额度，实际消耗取决于模型、任务复杂程度及运行方式。

例如，修改几行代码和分析一个大型GitHub仓库，即使都只提交一次任务，实际消耗也可能不同。

购买金额和Credits换算应以当前官方购买页面显示为准。本文不将未经确认的固定换算比例作为官方价格。

Codex Credits怎么扣费？本地任务和云端任务一样吗？

Codex使用量与模型和任务规模有关。

影响消耗的因素包括代码库大小、读取的文件数量、任务执行过程、推理强度及使用的功能。

本地Codex任务与云端任务可能采用不同的使用量计算方式，不能直接用某个模型的本地消息参考次数推算全部云端任务。

例如，让Codex修改网页上的一段文字，与让它检查整个网站、修改多个文件并运行测试，消耗的额度可能明显不同。

如果想减少不必要的额度消耗，可以把任务要求写清楚，限定需要修改的文件和目标，避免让Codex反复执行不相关的检查。

Credits的有效期、退款条件及可用范围应以购买时显示的官方条款为准，不能假定所有Credits永久有效或支持无条件退款。

Codex Plus额度用完怎么办？

Plus包含Codex使用权限，但不是无限使用。

根据适用的套餐规则，Codex可能存在5小时和每周使用限制。

当额度不足时，可以查看Usage页面中的剩余额度和重置时间。

如果只是偶尔达到限制，可以等待额度恢复，或者查看账号是否支持购买额外Credits。

如果每周都频繁达到上限，升级Pro可能比反复补充额度更方便。

07

5小时额度和每周额度有什么区别？

5小时额度限制的是适用时间窗口内的使用量。

每周额度则限制较长周期内的总使用量。

因此，5小时窗口恢复后，不代表每周额度也已经恢复。

实际剩余额度、限制类型和恢复时间应以当前账号Usage页面为准。

国内没有海外信用卡，Codex怎么付款？

Codex Credits的付款方式取决于账户、所在地区、套餐及当前官方结账选项。

OpenAI并未将支付宝或微信公布为所有Codex Credits购买场景通用的官方付款方式。

如果当前结账页面要求银行卡，需要使用符合OpenAI要求的付款工具。

Visa或Mastercard标志不代表一定可以完成付款。发卡地区、银行国际交易限制、身份验证及付款资格都可能影响结果。

截至2026年10月29日，中国大陆不在OpenAI公布的ChatGPT支持地区名单中。使用其他付款工具不能消除地区资格限制。

如果通过Apple App Store或Google Play购买ChatGPT会员，还需要区分会员订阅与Codex额外Credits。能够通过应用商店购买Plus，并不代表同一渠道一定支持购买Codex Credits。

Codex Credits可以自动充值吗？

符合条件的个人账号可以在Usage相关设置中查看自动充值选项。

如果启用自动充值，当Credits余额低于设定阈值时，系统可能通过保存的付款方式购买Credits，补充到设定的目标余额。

例如，可以设置最低余额、充值目标以及适用的每月自动充值上限。

如果不希望发生额外扣款，应检查自动充值是否开启。

自动充值的每月上限主要用于限制自动购买金额，不应理解为所有一次性购买和使用成本的统一上限。

Codex Credits会过期吗？可以退款吗？

根据OpenAI个人套餐Credits规则，购买的Credits有效期为12个月，未使用的余额到期后不会自动结转。

Credits原则上不可退款，但法律、合同要求或经核实的特定例外情况可能适用退款处理，例如确认的账单错误或未经授权交易。

Credits也不能随意转移到其他账号、转售或兑换现金。

14

Codex充值成功，但Credits没有到账怎么办？

如果已经付款，但Usage中没有显示新增Credits，可以检查以下内容。

  1. 确认登录的是购买时使用的ChatGPT账号。
  2. 打开Settings → Usage，或者Codex应用中的Usage & Billing。
  3. 检查Credits余额和最近使用记录。
  4. 确认购买的是个人使用Credits，而不是API平台余额。
  5. 查看付款收据，确认订单是否最终完成。
  6. 如果余额仍然没有更新，通过OpenAI帮助中心联系支持。

如果银行显示待处理或预授权，不代表Credits已经购买成功。

已经正式扣款但余额未更新时，应保留订单编号、金额和交易时间，不要立即重复付款。
